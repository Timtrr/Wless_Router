# Wless_Router

Самодостаточный комплект «VPN-маршрутизатора» для дома: поднимаешь на своём сервере (VPS или VM) WireGuard + sing-box + веб-панель, подключаешь роутер Keenetic — и вся домашняя сеть ходит через VPN по спискам доменов, без установки чего-либо на телефоны и ПК. Поддерживает резервные ноды из подписки и подключение к собственному серверу Amnezia (AmneziaWG) как основному каналу.

> ⚠️ **Статус: АЛЬФА, написано нейросетью.** Весь код (инсталлер, панель, сценарии) написан ИИ-ассистентом и обкатан на одной живой связке: Keenetic N6 → WireGuard → Ubuntu VM в Proxmox → свой VPS (AmneziaWG + подписка VLESS). На других конфигурациях не проверялось. Всё, что делаешь — на своих серверах и на свой страх и риск; инсталлер бэкапит конфиги, но гарантий нет. Багрепорты и правки приветствуются.

## Схема работы

```
телефоны/ПК/ТВ (домашняя LAN)
        │  (ничего не установлено, трафик идёт сам)
        ▼
роутер Keenetic — DNS-маршрутизация по спискам доменов
        │  домены из списка → WireGuard-туннель (hiddifywg), остальное — напрямую
        ▼
сервер с этой панелью (VPS или VM)
        │  iptables REDIRECT: TCP туннеля → sing-box (порт 12345)
        ▼
sing-box — выбирает исходящий по приоритету:
        ├─ amnezia-vm  — AmneziaWG-туннель до ВАШЕГО сервера Amnezia (основной)
        └─ reserve     — urltest-группа из VLESS-нод вашей подписки (резерв)
        ▼
интернет
```

Ключевая идея: **роутер решает, ЧТО идти через VPN (по спискам доменов), сервер решает, КАК (какой канал).** Один раз настроено — работают все устройства дома, включая те, где VPN-приложение поставить нельзя (ТВ, приставки, IoT).

## Состав комплекта

| Компонент | Что делает |
|---|---|
| **WireGuard-сервер** | интерфейс `hiddifywg`, порт `29687/udp` (настраивается), MASQUERADE, форвардинг. Приём трафика с роутера и устройств |
| **wg-redirect** | iptables-правила: TCP из туннеля → sing-box; QUIC (UDP/443) отклоняется, чтобы клиенты не зависали на HTTP/3 |
| **sing-box 1.14.4** | ядро маршрутизации: принимает туннельный трафик, держит подписку VLESS-нод, подключение к AmneziaWG, группы приоритета с автофейловером |
| **Веб-панель** (`app.py`, порт `8099`) | управление всем из браузера, вход по паролю с cookie-сессией |

## Веб-панель

Две вкладки:

**«Главная»** — статус в один экран: какой узел сейчас работает и его задержка, жив ли туннель Amnezia (эндпоинт, рукопожатие, rx/tx), активный режим приоритета.

**«Настройки»** — карточки:
- **Серверы** — список VLESS-нод из подписки, задержки, включение/выключение.
- **Подписка** — импорт URI-листа или xray-JSON, обновление одним кликом (ваши AWG-исходящие при обновлении не трогаются).
- **WireGuard-пиры** — добавление/удаление устройств и роутеров, конфиги для скачивания.
- **Amnezia** — вставляете AWG-профиль из приложения AmneziaVPN («свой сервер»), панель валидирует его, поднимает туннель `awg0` и держит связь; можно перезапустить или заменить профиль. Обфусцированный WireGuard (мусорные заголовки) проходит там, где обычный WG режут.
- **Приоритет** — режим «мой сервер» (основной — ваш AmneziaWG; пропал — авто-переход на резерв из подписки, ожил — авто-возврат) или «самый быстрый» (выбор минимальной задержки). Переключения не рвут живые соединения; фоновый поток панели проверяет канал каждые 30 секунд.

## Сценарии применения

### 1. Весь дом через свой сервер
Настройка один раз: инсталлер на сервер → роутер в панель как пир → домены (youtube, instagram, discord, что угодно) в списки роутера. Все устройства ходят через ваш сервер без единого VPN-приложения. Отдельные сервисы при желании остаются напрямую.

### 2. «Чтобы не отваливалось» — отказоустойчивость
Основной канал — ваш сервер (полный контроль, свой IP). Умер сервер/туннель — панель за пару минут сама переключит трафик на резервные ноды подписки, оживёт — вернёт обратно. Живые соединения при переключениях не обрываются, пользователи этого не замечают.

### 3. Свой сервер Amnezia как главный канал
AmneziaWG — это WireGuard с обфускацией (мусорные пакеты и нестандартные заголовки), который DPI не опознаёт как VPN. Вставляете профиль из приложения AmneziaVPN в карточку «Amnezia» — и ваш сервер становится основным выходом, а подписка — страховкой. Работает и наоборот: панель как мост между роутером и Amnezia там, где приложение Amnezia на роутер не ставится.

### 4. 4G-модем и «белые списки» оператора
Ситуация: оператор даёт «безлимит», но по белому списку адресов/портов (терминальные и IoT-тарифы, некоторые безлимитные опции). Практика показывает: если у вас на телефоне через 4G работает подписка (VLESS/Reality и подобные) — значит протокол проходит сквозь операторский фильтр, потому что неотличим от обычного HTTPS на разрешённые адреса.

Значит, тот же трюк работает и на ПК/сервере с 4G-модемом вместо проводного провайдера: модем (USB или в роутер) как аплинк → WG/AWG-туннель до сервера с этой панелью → дальше sing-box с вашими VLESS-нодами подписки. Телефон-то ходит через ту же подписку — сервер просто делает то же самое, но сразу для всей машины/сети.

Нюансы, о которых честно:
- если оператор режет **нестандартный UDP** (WireGuard-рукопожатие не пройдёт) — WG-звено не поднимется, нужен вариант туннеля поверх TCP или разрешённого порта;
- если белый список привязан к DPI (пропускает только конкретные SNI) — помогать будет именно VLESS/Reality поверх TLS, как в подписке;
- на тарифах с «только разрешённые адреса» без открытого TLS-транзита может не сработать вовсе. Это теория, проверенной конфигурации нет — проверите на своём операторе, отпишитесь в issue.

## Установка

```bash
sudo bash panel-installer.sh
```

Опции:

```bash
sudo bash panel-installer.sh --port 29687                        # порт WG
sudo bash panel-installer.sh --router-pub <ПУБЛИЧНЫЙ_КЛЮЧ_РОУТЕРА>  # сразу добавить пир-роутер
sudo bash panel-installer.sh --sub "https://ссылка-на-подписку"   # импорт подписки сразу
```

Инсталлер самодостаточный (~35 МБ): бинарник sing-box встроен, из интернета ничего не качается. Ключи, пароль панели и пиры генерируются при каждой установке — в скрипте нет ничего личного. В конце печатает: публичный ключ WG, пароль панели, адрес панели и пошаговую настройку Keenetic.

Повторный запуск безопасен: ключи и пиры сохраняются (бэкап конфига рядом), роутер можно добавлять позже:

```bash
sudo bash panel-installer.sh --router-pub <ключ>
```

## Требования

- Ubuntu/Debian (apt), архитектура x86_64, права root. Подойдёт дешёвый VPS (1 vCPU / 512 МБ) или VM в вашем Proxmox.
- Подписка на VLESS-ноды (для резервного канала) — опционально.
- Сервер AmneziaVPN «свой сервер» и AWG-профиль клиента — для основного канала через Amnezia.

## Известные особенности

- QUIC/HTTP-3 сознательно блокируется на роутере — сайты автоматически переходят на TCP, ничего не ломается.
- Рукопожатие AmneziaWG каждые ~2 минуты даёт краткий всплеск задержки (0,5–1 с) — это нормально, не неисправность.
- Панель рассчитана на один админ-пароль (генерируется при установке), сменить можно в настройках.
