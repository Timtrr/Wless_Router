# Wless_Router

Универсальный установщик «VPN-панели» для чистого сервера: **WireGuard + sing-box + веб-панель** в одном файле.

`panel-installer.sh` — самодостаточный скрипт (~35 МБ): внутри уже встроен бинарник sing-box 1.14.4 (x86_64), ничего из интернета качать не нужно. Ключи, пароль панели и пиры генерируются заново при каждой установке — ничего личного в скрипте нет.

## Что ставит

- **WireGuard-сервер** — интерфейс `hiddifywg`, порт `29687/udp` (настраивается), MASQUERADE и правила форвардинга.
- **sing-box** — входы: `socks 127.0.0.1:2100` и `redirect 0.0.0.0:12345` (приём перенаправленного туннельного трафика напрямую, без промежуточных прокси).
- **Перенаправление** (`wg-redirect`) — iptables-правила: TCP из туннеля → sing-box, QUIC (UDP/443) отклоняется, чтобы клиенты не висли на HTTP/3.
- **Веб-панель** — порт `8099`: список серверов, импорт подписки (URI-лист и xray-JSON), управление WireGuard-пирами, смена пароля. Вход по паролю с cookie-сессией.

## Установка

```bash
sudo bash panel-installer.sh
```

Опции:

```bash
sudo bash panel-installer.sh --port 29687                        # порт WG
sudo bash panel-installer.sh --router-pub <ПУБЛИЧНЫЙ_КЛЮЧ_РОУТЕРА>  # сразу добавить пир-роутер
sudo bash panel-installer.sh --sub "https://ссылка-на-подписку"   # импорт подписки сразу
```

В конце установки скрипт печатает: публичный ключ WG, пароль панели, адрес панели и пошаговую настройку роутера (Keenetic).

## Схема работы

```
клиенты LAN → роутер (DNS-маршрутизация по спискам доменов)
            → WireGuard-туннель → сервер (этот инсталлер)
            → iptables REDIRECT → sing-box → VLESS-серверы подписки
```

Домены из списков роутера уходят в туннель, остальное — напрямую.

## Повторный запуск безопасен

Ключи и существующие пиры сохраняются (бэкап конфига создаётся рядом), так что роутера можно добавлять позже:

```bash
sudo bash panel-installer.sh --router-pub <ключ>
```

## Требования

- Ubuntu/Debian (apt), архитектура x86_64.
- Права root.
